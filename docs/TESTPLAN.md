## Notes for Stakeholder Sign-off

- Use Actual Result, Status, and Comments columns during walkthrough sessions.
- Mark any behavior that is unclear, inconsistent, or runtime-dependent as a decision item before Node.js implementation.
- For migration readiness, convert each approved case into:
  - Unit tests for operation rules (credit, debit, insufficient funds, validation)
  - Integration tests for end-to-end menu action to balance update flow
